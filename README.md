# Roundtable

Get several AI models talking at once: debate, collaborate or discuss, with you at the table.

**Open it:** https://renzouw.github.io/roundtable/

- Works with Claude, GPT, Gemini, Grok, any OpenRouter model, or a local model (Ollama, LM Studio).
- Debate mode with a judge or jury verdict, a "where everyone stands" summary, moderators and presets.
- Installs as an app on Android, iPhone and desktop, and opens offline.

## Privacy

There is no server. The app runs entirely in your browser and talks straight to the AI providers you choose.
Your API keys and conversations are stored only in your own browser, on your own device. They are never
sent anywhere except to the provider you're using, and they are not part of this repository.

## Install on your phone

- **Android (Chrome):** open the link, then tap **Install** in the app's sidebar (or the browser menu → *Install app*).
- **iPhone (Safari):** open the link, tap **Share** → **Add to Home Screen**.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole app |
| `manifest.webmanifest` | App name, icon and colors for installing |
| `sw.js` | Lets the app open offline (never touches API calls) |
| `icons/` | App icons |
